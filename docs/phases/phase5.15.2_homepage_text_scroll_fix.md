# Phase 5.15.2: 首页乱码与聊天滚动修复

> 状态：进行中
> 类型：前端 UI 修复
> 前置阶段：Phase 5.15 首页聊天接入内置 OpenClaw

## 目标

修复 `workspace-clone` 首页中可见文案的乱码问题，并恢复聊天消息区域的独立滚动能力，确保长会话下仍能浏览历史消息。

## 本次范围

- 校正首页侧栏、目录区、聊天区、抽屉和弹层中的乱码文案
- 调整聊天主区布局，让消息列表成为可滚动层
- 保持现有网关聊天接入、`invoke()` 调用和事件处理逻辑不变

## 验收标准

- 首页不再出现明显乱码文案
- 聊天消息较多时可以在消息区内滚动查看历史内容
- 输入区保持固定在底部，不随消息内容被顶出可视区域
- `npm run build` 可以通过
