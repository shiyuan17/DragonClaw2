# Phase 5.15.2: 首页乱码、滚动与侧边栏优化

> 状态：进行中
> 类型：前端 UI 修复
> 前置阶段：Phase 5.15 首页聊天接入内置 OpenClaw

## 目标

修复 `workspace-clone` 首页中的乱码与聊天滚动问题，并继续将左侧主侧栏调整到更接近参考图的轻量化工作台样式。

## 本次范围

- 校正首页侧栏、目录区、聊天区、抽屉和弹层中的乱码文案
- 调整聊天主区布局，让消息列表成为可滚动层
- 将左侧主菜单改为参考图中的横向图标加文字排布
- 收敛侧栏顶部按钮、菜单留白、品牌水印和底部操作按钮层级
- 恢复聊天消息正文的文本选择能力，允许用户直接框选复制会话内容
- 保持现有网关聊天接入、`invoke()` 调用和事件处理逻辑不变

## 验收标准

- 首页不再出现明显乱码文案
- 聊天消息较多时可以在消息区内滚动查看历史内容
- 左侧主菜单在展开态下接近参考图的横向列表样式
- 底部品牌区与反馈/管理员按钮的层级更贴近参考图
- 聊天气泡正文可直接鼠标框选并复制，不影响现有按钮点击与滚动
- `npm run build` 可以通过
