# Phase 5.9: Git 忽略规则清理

> 状态：待实现

## 目标

排查 `node_modules` 仍进入 Git 提交范围的原因，并确保依赖目录在后续开发中不再被纳入提交。

## 问题判断

- 根目录 `.gitignore` 已包含 `node_modules` 规则。
- `node_modules` 仍出现在待提交列表，说明它已经被 Git 跟踪并进入索引。
- 仅保留忽略规则不足以清理已跟踪文件，还需要从索引移除但保留本地目录。

## 实施方案

1. 补强根目录 `.gitignore`，保留并明确 `node_modules` 目录忽略规则。
2. 使用 Git 仅从索引移除 `node_modules`，不删除本地依赖目录。
3. 验证 `git status` 不再将 `node_modules` 视为待提交内容。
4. 更新 `docs/TODO.md`，将本阶段任务标记完成。

## 验收标准

- `node_modules` 不再出现在 `git status` 的待提交范围内。
- 本地 `node_modules` 目录仍然保留，可继续用于开发。
- 后续重新执行 `npm install` 不会再次把依赖目录带入提交。
