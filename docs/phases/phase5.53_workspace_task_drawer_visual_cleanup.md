# Phase 5.53: Workspace 任务抽屉样式收敛

## Summary
- 在不改真实 `cron` 管理逻辑、不改 `invoke()/Gateway RPC` 契约的前提下，重做 `workspace-clone` 右侧“任务”抽屉的列表样式。
- 视觉方向采用“保留当前 ElevenLabs 主题，只借图 2 的结构与交互”：更扁平、更紧凑、更清晰，不做整块深色主题迁移。
- 本期只改 `workspace-clone` 的 `.tsx/.css` 渲染层；保留当前内部 panel key `schedule`、真实任务数据、编辑弹窗、启停/删除/立即运行能力。

## Implementation Changes
- 文档先行：
  - 新增 `docs/phases/phase5.53_workspace_task_drawer_visual_cleanup.md`，记录目标图意图、信息层级调整、交互约束、验收标准。
  - 在 `docs/TODO.md` 新增对应 `[ ]` 条目。
  - 文档 commit 与代码 commit 分开，继续遵守现有 Dev Cycle。

- 任务抽屉主结构：
  - 只调整 `WorkspaceCloneUtilityDrawer.tsx` 与 `workspace-clone.css` 的任务区渲染。
  - 保留顶部“启用中 / 已停用”双 tab，但改成更明确的横向 pill 样式，避免当前拥挤感。
  - 去掉当前“大卡片 + 大段元信息 + 四个并列大按钮”的呈现方式，改为“紧凑任务行”。
  - 每条任务默认折叠，只展示高优先级信息：
    - 任务名
    - 一行描述或 payload 摘要
    - 调度摘要
    - 下次运行时间
    - 最近一次结果短摘要
    - 状态标签
  - 关闭态不再展示 2x2 元信息网格，不再把唤醒模式、任务 ID、投递预览、最近耗时全部铺开。

- 行内交互收敛：
  - 保留点击任务行的现有选择行为，不新增后端逻辑，也不改选择后的真实 runs 加载逻辑。
  - 保留一个轻量的直接操作：
    - `立即运行` 改为小型图标按钮或轻量按钮，放在行右侧。
  - 次级操作统一收进 `更多` 菜单：
    - 启用/停用
    - 编辑
    - 删除
  - `systemEvent` 以外任务的“编辑不可用”规则保持不变，在 `更多` 菜单中继续禁用并给出提示。
  - 不新增“新建任务”按钮，不恢复任何创建入口。

- 选中态与详情层级：
  - 保留“选中一条任务后可看到更多内容”的能力，但将展开区压缩成轻量 footer，而不是当前大面积扩展面板。
  - 选中态只补充最近运行记录列表，数量控制在最近 2-3 条，作为抽屉内的快速查看。
  - 全量详情仍由现有 `relatedResource === "schedule"` 详情面板承载；该面板可做轻量样式同步，但不改其真实数据来源和结构职责。
  - 编辑弹窗 `WorkspaceCloneTaskEditorModal` 保持功能不变，仅在必要时微调入口文案或禁用态表现，不改字段逻辑。

- 样式与 token 约束：
  - 全部沿用现有 `--dc-workspace-*` / `--dc-*` token，不引入独立的任务子主题。
  - 任务区重点优化：
    - 卡片高度与内边距收紧
    - 标题、摘要、次信息建立更明确层级
    - 状态标签缩小
    - 行尾操作区变轻
    - expanded 区与常态信息分离
  - 复用现有 `workspace-clone__more-menu` / drawer / status 视觉语言，不新造一套菜单系统。
  - 移动端或窄宽度下，任务行改为自然换列，但仍保持“信息优先、操作收敛”的顺序。

## Public Interfaces / Type Notes
- 不修改任何 Tauri command、Gateway RPC、`invoke()` 参数、hook 返回结构或 `WorkspaceCron*` 类型定义。
- 不修改真实任务过滤、加载、编辑、启停、删除、立即运行、runs 查询逻辑。
- 如需本地状态，仅限抽屉内部的展示态，例如：
  - 当前打开的 `更多` 菜单项
  - 当前折叠/展开的视觉态
- 这些状态限定在前端组件内部，不外扩为新的公共接口。

## Test Plan
- 文档流程：
  - 先提交 phase 文档与 `docs/TODO.md`。
- 视觉验收：
  - 任务抽屉列表改为紧凑行式布局，明显比当前更整洁。
  - “启用中 / 已停用” tab 为横向清晰 pill，不再显得拥挤。
  - 行内不再出现 4 个大号并列操作按钮。
  - 默认列表不再堆叠大量元信息，信息焦点落在名称、调度、下次运行、结果摘要、状态。
- 功能回归：
  - 点击任务仍能选择任务并加载最近运行记录。
  - `立即运行`、启停、编辑、删除仍调用现有真实任务 handler。
  - 不支持编辑的任务类型仍正常展示、可启停/运行/删除，编辑入口维持禁用提示。
  - Gateway 未连接、加载中、空态、错误态文案与真实行为不回退到 mock。
  - `relatedResource` 的“任务详情”面板仍可正确展示已选任务详情与运行记录。
- 检查项：
  - `npm run check:encoding`
  - `npm run check:file-size`
  - `npm run tauri dev`
  - 手动验证首页聊天工作区：任务抽屉样式变更后，聊天、历史、memory/skills/tools/channel 面板无回归。

## Assumptions
- 采用“保留现主题，只借图 2 的结构与交互”作为默认方案，不做深色重绘。
- 本期是任务抽屉的信息架构与视觉收敛，不扩展任务创建能力。
- 不改任务数据模型，不改 `cron` 真实管理能力，只重排显示优先级和操作入口。
- 抽屉内只保留轻量运行记录预览；完整详情仍以现有详情面板为主，而不是把所有信息再次塞回列表卡片。
