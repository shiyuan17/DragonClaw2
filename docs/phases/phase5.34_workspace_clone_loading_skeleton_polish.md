# Phase 5.34: workspace-clone 切换加载骨架优化
> 状态: Planned
> 日期: 2026-05-03
> 类型: 前端视觉优化 / loading skeleton

## 背景

`workspace-clone` 主内容区在切换“数字员工 / 技能市场”时，会展示一套偏正文说明式的 loading 占位。当前样式层级过散，视觉重心不够集中，和图 3 那种更规整的卡片式骨架相比显得凌乱。

## 目标

- 将主内容区切换时的 fallback 重做为更干净的卡片式骨架。
- 保持 `invoke()`、事件处理、数据流和模型配置弹层现状不变。
- 仅使用现有 `--dc-*` 主题 token 和 workspace 语义样式。

## 实施范围

### 1. 主内容区骨架重排
- 为“数字员工 / 技能市场”单独提供一套专用 loading 骨架。
- 采用更收敛的层级：轻量标签、整齐的占位线条、明确的卡片边界与留白。
- 去掉当前偏说明文案的散乱布局，让加载态更像统一的内容框架，而不是正文页面。

### 2. 样式调整
- 在 `src/styles/workspace-clone.css` 中补充新的 loading 结构样式。
- 只用现有设计 token 组织圆角、边框、阴影、间距和颜色。

## 验收标准

- 切换“数字员工 / 技能市场”时，骨架屏更整洁、层级更清晰，不再出现杂乱的说明式布局。
- 模型配置弹层的 loading 表现不变。
- `npm run build` 通过。
