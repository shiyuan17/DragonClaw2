# Phase 5.15.3: 顶部标题栏与右侧会话边栏重构

> 状态：规划中
> 类型：前端 UI 重构
> 前置阶段：Phase 5.15.2 首页乱码、滚动与侧边栏优化

## 目标

基于现有 `workspace-clone` 聊天首页，按参考图继续收敛整体结构，将当前“聊天工作台”调整为更完整的双层头部布局，并把会话配置能力集中迁移到右侧会话边栏。

本轮重构只处理前端渲染层和本地 UI 状态，不调整任何 `invoke()` 调用、hooks 业务逻辑、Tauri 配置或 Rust 命令。

## 本次范围

- 在 `workspace-clone` 首页顶部新增一条应用内仿标题栏
- 重排聊天区头部，让右上角主入口负责展开右侧会话边栏
- 将右侧抽屉升级为默认服务当前会话的详情边栏
- 把 `模型 / 记忆 / 技能库 / 命令 / 工具权限` 从 composer 与 overlay 主入口迁移到右侧边栏首屏
- 保留 `历史 / 日志 / 定时任务详情` 为次级入口，不占据右栏首屏主层级
- 调整相关前端类型定义与本地 UI 状态，保持数据来源不变

## 不包含

- 新增或修改任何 Tauri / Rust 命令
- 修改 `invoke()` 名称、参数或返回类型
- 迁移 `useService / useConfig / useSetup / useLogs / useWorkspaceGatewayChat` 逻辑
- 改动 `chat` 以外菜单的深层业务行为
- 接管原生窗口装饰或改造 `tauri.conf.json`

## 关键设计

### 1. 双层头部

- 第一层为应用内仿标题栏：左侧品牌区，中部轻量拖拽观感区，右侧视觉控制区
- 第二层为聊天会话头部：左侧会话身份，右侧保留少量操作按钮
- 两层都以浅色、弱分割、低视觉重量处理，避免再次出现厚重卡片感

### 2. 右侧会话边栏

- 默认收起，通过聊天头部右上角主按钮展开
- 首屏固定承接：
  - 会话身份卡
  - 快捷卡片：`模型`、`记忆`、`技能库`、`命令`、`工具权限`
  - 补充卡片：`频道`、`定时任务`
  - 底部元信息区：模型、员工 ID、工具权限摘要、所属频道、最近产出等
- `历史 / 日志 / 定时任务详情` 仍由次级入口打开

### 3. 入口迁移策略

- 右侧边栏成为会话配置能力的主入口
- composer 原有 pills 仅做弱化保留，点击后优先展开右栏并聚焦对应模块
- overlay / modal 继续保留为二级详情容器，但不再承担这些资源的主导航职责

## 验收标准

- 首页顶部出现应用内仿标题栏，整体观感接近参考图
- 聊天区头部更轻量，且右侧会话边栏默认关闭
- 点击头部入口后可展开右侧会话边栏
- 右栏首屏可见：模型、记忆、技能库、命令、工具权限、频道、定时任务
- composer 中旧入口被弱化，但仍能联动打开右栏对应模块
- 历史 / 日志仍能从次级入口访问
- `chat` 以外菜单与现有网关聊天链路不回归
- `npm run build` 可以通过
