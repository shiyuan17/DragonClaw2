# Phase 5.35: workspace-clone 存量乱码文案清理
> 状态: Planned
> 日期: 2026-05-03
> 类型: 前端文案修复 / encoding cleanup

## 背景

`workspace-clone` 的部分前端文案存在历史错码残留。仓库跟踪文件整体仍可按 UTF-8 正常读取，问题集中在少量真实存储的错误中文字符串，而不是全仓编码策略失效。

## 目标

- 将 `workspace-clone` 已定位的错码中文文案恢复为正常中文。
- 清理为错码标签保留的兼容判断分支，保持当前懒加载和页面行为不变。
- 严格限制在前端渲染层字符串修复，不改动 `invoke()`、事件处理、后端命令签名和 Rust 文件。

## 实施范围

### 1. 反馈标题与提示语修复
- 修复数字员工、模型配置、记忆、技能库、工具权限、技能市场、技能安装等反馈标题中的错码中文。
- 修复频道绑定保存成功、移除绑定成功提示中的错码中文。

### 2. 懒加载标签兼容分支清理
- 移除 `WorkspaceClonePage` 中针对错码标签的 `label.includes(...)` 兼容判断。
- 保留当前正常中文标签判断，避免影响 `workspace-clone` 的 fallback 逻辑。

## 验收标准

- `workspace-clone` 中本次已定位的错码 token 全部清理完成。
- 数字员工 / 技能市场 / 模型配置的懒加载标题正常显示。
- 记忆、技能库、工具权限和频道绑定相关反馈提示显示正常。
- 仓库文本扫描仍无 UTF-8 非法文件。
