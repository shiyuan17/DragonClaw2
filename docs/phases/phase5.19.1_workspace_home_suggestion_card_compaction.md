# Phase 5.19.1: workspace-clone 首页场景卡片紧凑化

> 状态：待验收
> 类型：前端视觉压缩 / 渲染层微调

## 目标

在不改动任何聊天逻辑、事件处理或 `invoke()` 调用的前提下，缩小 `workspace-clone` 首页欢迎区的场景卡片，让卡片行本身更紧凑，减少它对输入区上方可视空间的占用。

## 本次范围

- 收紧首页场景卡片的最小高度、内边距、图标尺寸与文案密度。
- 缩小场景卡片之间的间距，以及卡片行上下留白。
- 将新增的尺寸语义沉淀到 `src/styles/tokens.css` 的 `--dc-workspace-*` token 层，再由 `src/styles/workspace-clone.css` 消费。

## 不包含

- 不修改 `WorkspaceCloneChatView` 之外的业务行为。
- 不修改欢迎态文案、卡片点击逻辑或聊天输入交互。
- 不重排卡片数量，也不改动移动端断点策略。

## 验收标准

- 首页欢迎态的 5 张场景卡片比当前版本更矮、更紧凑。
- 卡片标题与描述仍保持可读，不出现布局错位或按钮热区异常。
- 输入框区域在同一视口下获得更大的可见空间。
